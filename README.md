# RackStudio

Интерактивный веб-конструктор серверных стоек 19", системой изоляции кабельных трасс по рабочим местам и менеджером CLI-конфигураций коммутаторов.

---

## Быстрый запуск

1. Дважды кликните по ярлыку на рабочем столе: **`Запустить RackStudio.bat`**  
   *(или запустите `start.bat` внутри папки `rack-studio`)*.
2. Автоматически откроется браузер по адресу: **`http://localhost:8080`**.

---

## Ключевые возможности

### 1. Группы соединений и изоляция рабочих мест (Workplace Scope Isolation)
- Патч-корды и порты можно группировать по рабочим местам или сервисам.
- **Мгновенный фильтр:** при клике на бейдж рабочего места в верхней панели все остальные кабели стойки плавно затухают (или полностью скрываются), а кабели и задействованные порты выбранного рабочего места ярко подсвечиваются неоновым свечением Etherlighting.
- Никакой визуальной «каши» из сотен проводов — всегда видно, какая пара патч-кордов и портов отвечает за конкретное место.

### 2. Конструктор шаблонов оборудования (Custom Device Template Builder)
- Загрузка **реальной фотографии лицевой панели** устройства (JPG, PNG, SVG).
- Интерактивная расстановка портов кликом прямо по изображению панели.
- Настройка типов портов:
  - RJ45 (1G, 2.5G, 10G, PoE)
  - SFP / SFP+ (10G DAC / Оптика)
  - Консольный порт (Console)
  - Разъемы питания (C13 / C14)
- Быстрые генераторы блоков: `+ Блок 24x RJ45`, `+ 4x SFP+`.
- Ползунки точной подгонки позиции X/Y (%).
- Сохранение шаблона в локальную библиотеку стойки.

### 3. Менеджер CLI-конфигураций коммутаторов
- Окно терминала с синтаксической подсветкой для коммутаторов и маршрутизаторов.
- **Генерация конфига по портам (1 клик):** функция `Сгенерировать по портам` сканирует все подключенные к свитчу патч-корды, сопоставляет их с рабочими местами и автоматически генерирует:
  - Блоки `vlan <ID> name <Workplace>`
  - Описания портов: `interface GigabitEthernet0/X; description Link to PatchPanel-01:Port-1 [АРМ-1]`
  - Настройки `switchport mode access / trunk`, `spanning-tree portfast`, `power inline auto`
- Экспорт конфига в файл `.cfg`, импорт и копирование в буфер обмена.

### 4. Интерактивная коммутация патч-кордов
- Клик по порту источника $\rightarrow$ интерактивная линия тянется за курсором $\rightarrow$ клик по порту назначения.
- Реалистичные кривые Безье (провисание кабелей, естественный радиус изгиба).
- Настройка длины, цвета, типа кабеля (Cat6 UTP, Cat6A STP, SFP+ DAC, Оптика OM4/OS2).
- При клике на кабель открывается панель настройки и смена группы рабочего места в 1 клик.

### 5. Поддержка нескольких независимых стоек
- Создание произвольного числа независимых стоек (например, *«Главная серверная»*, *«Кроссовая 2 этаж»*).
- Настройка высоты стойки: 12U, 18U, 24U, 42U, 48U.
- Подсчет суммарного энергопотребления (Вт) и занятых юнитов.

### 6. Полная автономность (Local-First SPA)
- Все данные сохраняются локально в `LocalStorage`.
- Кнопка **Экспорт JSON** для создания резервной копии всего проекта.
- Кнопка **Импорт JSON** для восстановления или переноса на другой компьютер.
